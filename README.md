## 📋 Características

- 41 plantillas de flujo predefinidas por rubro
- 3 modos: Solo IA, Solo Flujo, Mixto
- Auto-asignación por rubro al aprobar negocio
- Motor determinista (<0.5s respuesta)
- Editor de flujos custom
- Integración con sgc-saas
